# 🎓 SGPA - Classroom Project Management System

**SGPA (Sistema de Gestión de Proyectos Académicos)**, also known as **Proactivo**, is a web-based platform designed to support the management and monitoring of academic degree projects in university institutions.

It allows students and faculty to schedule tutorials, evaluate progress using custom rubrics, and streamline the academic follow-up process.

---

## 🚀 Features

- 📆 Schedule personalized or group tutorials
- 📊 Track project progress and evaluation history
- 📋 Customizable rubrics for assessment
- 🔐 Role-based access control (students, tutors, coordinators)
- 🔄 Agile development structure to ensure scalability

---

## 💻 Tech Stack

- **Frontend:** PrimeFaces (XHTML, JavaScript, CSS)
- **Backend:** Java EE
- **Database:** MySQL
- **Version Control:** Git + GitHub

---

## 📐 Development Context

- Built for **Fundación Universitaria Colombo Americana - Unicolombo**
- Solved the lack of a centralized platform for managing degree projects
- Developed in an agile team environment using real academic requirements
